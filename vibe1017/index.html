인터넷에서 GitHub에 파일 올리기

설치나 터미널 없이 웹브라우저에서 할 수 있어요.

  1. GitHub에 로그인하세요.
  2. 새 저장소 만들기에서 이름을 입력하고 공개 범위를 선택하세요. README 추가를 켜고 Create repository를 누르세요. 이미 저장소가 있다면 바로 여세요.
  3. 저장소의 Code 탭에서 Add file → Upload files를 선택하세요.
  4. 컴퓨터 폴더 안의 파일을 업로드 영역으로 끌어 놓으세요. choose your files를 눌러 선택해도 됩니다.
  5. 업로드가 끝나면 변경 내용 설명을 적고 Commit changes를 누르세요.

파일을 수정했다면?

같은 저장소의 같은 경로에 수정한 파일을 다시 업로드하고 Commit changes를 누르세요.

기억하세요: 웹 업로드는 컴퓨터 폴더와 자동으로 동기화되지 않아요. 수정할 때마다 직접 올려야 합니다.

비밀번호와 개인 정보가 담긴 파일은 올리지 마세요.
